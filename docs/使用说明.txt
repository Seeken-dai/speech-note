演讲提词窗 · 便携版

启动
双击 SpeechNote.exe。无需安装、无需管理员权限、无需联网。
需要 Windows 10 2004 或更新版本（含 Windows 11），以及系统自带的 .NET Framework 4.8。
保留同目录的 SpeechNote.exe.config。也支持把讲稿文件拖到 EXE 图标上打开。
启动后仅在任务栏右下角系统托盘显示便签图标，不占用普通任务栏应用按钮。
单击托盘图标显示便签；右键菜单可显示／隐藏便签、切换控制区、打开讲稿和退出。
如果右下角没有直接显示图标，请在“显示隐藏的图标”的上箭头中查找。

阅读讲稿
1. 点击文件夹图标“打开讲稿”，选择 .md / .markdown / .txt 文件。
2. 鼠标移到正文上，用滚轮上下阅读；也可以拖动右侧细圆角滑块，或点击滑块所在区域跳转。
   滑块跟随浅色／暗黑主题，悬停时略微加粗；讲稿不足一屏时不显示滑块。
   正文为阅读展示区：鼠标保持普通箭头，不出现输入光标，单击或拖动不会选中文字。
   滚轮阅读、双击切换控制区、纯阅读时 Alt + 左键拖动便签均保留。
3. A− / A+ 图标每次调整 1 号字，支持 6～42 号（包括 6、7 号）；带横线的向上箭头回到开头。
4. 拖动便签顶部“演讲便签”区域移动窗口，拖动边缘或边角调整大小。
5. 底部滑块调整透明度：0% 完全不透明，80% 最透明。
6. Ctrl + Alt + H 隐藏或恢复窗口。带斜线的眼睛图标使用相同功能。
   右上角“−”将便签收起到系统托盘，单击托盘图标即可恢复。
   快捷键被其他软件占用时仍可隐藏，使用托盘图标恢复即可。
7. 顶部纸张图标“纯阅读”隐藏所有按钮、文件名、透明度设置、提示和滚动条，只保留讲稿。
   双击正文统一切换所有控制按钮的显示／隐藏：显示时双击隐藏，隐藏时再双击恢复。
   Ctrl + Alt + R 和托盘菜单也可切换。快捷键被占用时，仍可双击或使用托盘菜单。
   纯阅读时滚轮仍可翻阅；按住 Alt 拖动正文可移动便签，边缘仍可调整大小。
8. 顶部月亮图标切换为黑底白字；点击太阳图标返回暖黄色纸面。
   切换主题或纯阅读模式会尽量保留当前阅读位置，捕获排除仍然生效。
9. 鼠标悬停在图标上会显示完整用途。短横线为收起到托盘，叉号为退出程序。
   托盘右键“退出”也可彻底退出，并移除托盘图标。
10. 普通模式最小 260 × 240，纯阅读模式最小 160 × 90（随 Windows 显示缩放等比例变化）。
    用鼠标拖动边缘或边角缩小。恢复设置时会自动展开以容纳按钮，再进入纯阅读会恢复之前的小尺寸。

窗口保持置顶，并定期恢复置顶。普通点击阅读区不会抢走 PPT 的键盘焦点。
Windows 关闭“将鼠标悬停在非活动窗口上时对其进行滚动”时，悬停滚轮可能不响应；可拖动滚动条。
大小、位置、字号、透明度、主题和纯阅读模式保存在同目录 settings.ini。讲稿正文和路径不会写入设置。
目录不可写时仍能使用，但下次启动会恢复默认设置。

投屏隐藏：务必了解的适用范围
本工具始终启用 Windows WDA_EXCLUDEFROMCAPTURE，并读取系统状态确认。
保护设置失败或 Windows 版本不支持时，正文保持隐藏，不展示讲稿。
调整透明度时会重新检查保护状态。
“捕获排除已启用”表示 Windows 已接受设置，不表示钉钉或飞书的所有版本与共享方式都已验证。

首次使用时，请用无敏感内容的示例讲稿进行一次验证：
1. 打开讲稿，启动 PPT 放映。
2. 在钉钉或飞书开启实际要用的共享方式。
3. 用另一台设备或请一位观众检查共享画面，确认讲稿窗口不出现。
4. 调整大小和透明度，再检查一次；切换 PPT 后确认窗口仍在前方、滚轮可用。
5. 如仍能看到讲稿，停止共享，改为只共享 PPT 应用窗口，并再次验证。

钉钉/飞书或显卡的某些捕获方式可能不遵循 Windows 的排除设置，不能承诺所有情况下隐藏。
HDMI / 无线“复制屏幕”、采集卡与摄像头拍摄不受此机制保护；请用扩展显示器，把讲稿留在本机屏幕。
打开文件的系统选择框不属于讲稿窗口，建议在开始共享之前选好文件。
其他强制置顶窗口、系统安全桌面或独占全屏可能覆盖本窗口；不能保证盖住所有系统界面。
透明度只改变视觉效果，无法保证旁边的人看不到；需要时可用快捷键快速隐藏。

格式支持
中文 UTF-8（有/无 BOM）、UTF-16/UTF-32（有 BOM）、GB18030/常见 GBK 文本。
单文件上限 4 MB。
Markdown 支持标题、列表、粗体、斜体、引用、行内代码与代码块。
表格、复杂嵌套等高级 Markdown 语法按文本显示。链接只保留文字；图片仅显示说明，不加载远程资源。

开发与验证
源代码位于 src，使用 build.ps1 编译，不需要下载 SDK 或 NuGet 包。
自动检查：SpeechNote.exe --self-test <测试报告完整路径>
自检生成示例文件、内部界面预览和测试报告，不代表实际会议软件捕获测试。
